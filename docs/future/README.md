# Future Planning Docs

This folder stores planning docs that are useful for roadmap decisions but are not the current GD1 implementation baseline.

| Folder | Scope |
|---|---|
| `scm-roadmap/` | Full Kim Binh SCM planning across GD1, GD2, and GD3. |
| `gd2-wms/` | Warehouse receiving, inventory, and outbound planning. |
| `gd3-mrp/` | Production planning, BOM, MO, MRP, and forecast planning. |
| `costing/` | Cross-phase costing and financial rollup planning. |
| `mcp-ops/` | MCP/deploy/readiness planning and operational automation ideas. |

For current GD1 schema and workflow decisions, use `docs/context/PROJECT_CONTEXT.md`, `docs/context/OPERATING_MODEL.md`, `docs/database/GD1_DOCUMENT_ERD.md`, and `docs/modules/`.
