# Spacing And Grid Foundation

Use this when defining page density, responsive grids, and section spacing.

## Spacing

- Use compact vertical rhythm for operational tools.
- Prefer consistent gaps: small within controls, medium within sections, large between major page blocks.
- Keep table cells dense but readable.
- Do not create large hero-like vertical gaps on app screens.

## Grid

- Metrics: 1 column on mobile, 2 on tablet, 3-4 on desktop depending on content.
- Forms: 1 column on mobile, 2 columns on medium screens, more only when fields are short and related.
- Detail summaries: use 2-column grids for label/value blocks where space allows.
- Tables: keep natural width and use horizontal scroll for wide operational data.

## Responsive Rules

- Do not shrink critical codes until unreadable.
- Let toolbars stack on mobile.
- Keep primary actions reachable near the page header.
- Avoid layouts where filters push content below the fold unnecessarily.

## Stable Dimensions

Use stable dimensions for:

- icon buttons.
- badges.
- progress bars.
- filter controls.
- table row actions.
- calendar cells.

This prevents hover states, long labels, or dynamic counts from shifting the layout.
