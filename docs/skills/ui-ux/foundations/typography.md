# Typography Foundation

Use this to keep text hierarchy consistent across operational screens.

## Hierarchy

- Page title: route/module name.
- Section title: group of related operational content.
- Table header: short nouns.
- Detail labels: compact uppercase or muted labels.
- Body text: direct operational copy.

## Rules

- Do not use hero-scale type inside dashboards, tables, sidebars, drawers, or compact panels.
- Do not scale font size with viewport width.
- Keep letter spacing normal.
- Prefer readable sentence case for UI labels.
- Keep data values exact: preserve uppercase enum values when the value itself matters.

## Copy Density

- Use short labels: `ETA`, `Deadline`, `Supplier`, `Risk`, `Tasks`.
- Use one-sentence helper text under major page titles only.
- Avoid teaching users how to use obvious UI controls in visible app copy.

## Data Text

- Codes such as `PR-2026-000145`, `PO-4500098123`, `DO-2026-000087` should be visually stable and easy to scan.
- Pair business codes with a second line when useful: supplier, item, status, or date.
