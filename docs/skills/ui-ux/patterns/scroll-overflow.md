# Scroll And Overflow Pattern

Use this to keep dense ERP screens usable across desktop and mobile.

## Page Scroll

- Prefer one main vertical scroll surface.
- Avoid nested vertical scrolling unless a drawer/table requires it.
- Keep page header and toolbar stable enough that users can regain context.

## Table Overflow

- Use horizontal scroll for wide operational tables.
- Keep first columns meaningful so users know what row they are viewing.
- Avoid squeezing codes or dates into unreadable widths.

## Drawer Overflow

- Drawer body can scroll independently.
- Keep drawer header visible when possible.
- Do not put large nested tables inside narrow drawers unless horizontally scrollable.

## Text Overflow

- Long supplier names, item names, document names, and blocked reasons should wrap or truncate intentionally.
- Buttons should not resize unpredictably on hover.
- Badges should stay readable; use counts when labels get too long.
